BIRANAYE PWA STARTER

1) Extract this ZIP on your Android phone.
2) Open config.js with a text editor.
3) Replace the two placeholder strings with your Supabase Project URL and Publishable key.
4) Save the file.
5) Deploy the folder to an HTTPS static host before testing login. Do not open index.html directly from your file manager.

Never put an sb_secret_ or service_role key in config.js.

This is an early prototype: email signup/signin, browse published book listings, create book drafts. It does not yet provide a chapter editor, protected PDF delivery, payments, wallet, moderation, or production-ready publishing. Payment confirmation must be server-side. Review database security before launch.
